hexo(三)写博客&发博客

Posted on 2024-06-02 Edited on 2024-07-13 In 工具篇 , hexo | 搭建静态博客

1. 发博客流程

  1. hexo new [options] title # 建立一个名为title.md文件
    • title.md的图片等附件
      • 如果配置了_config.yml中的default_layout参数则是默认会建立一个与title同名的文件夹用于存放title.md需要用到的.png等文件.(而且必须这样存放)
    • tilte.md的路径
      • title.md会放在根目录/source/_posts下,这里面存的就是要发出去的文章.可以根据分类在_posts下自由放置在比如”工具篇”的文件夹下,并不影响.
    • [options]
      • [options]主要只使用-p 或者 --path参数用来指示文件建立路径.
  2. 编辑title.md文件内容
  3. hexo generate # 生成静态网页文件
  4. hexo server # 启动本地端口预览
    • 默认本地预览端口
      • 默认端口为4000,访问网址http://localhost:4000/.
    • 设置本地预览端口
      • 有时候4000端口会被占据或者出错,这时候需要重设预览端口
      • $ hexo server -p 4001 # 可以重设端口为4001
  5. hexo deploy # 把静态文件部署在网页(github.io)上
  6. 其他
    • $ hexo g & hexo d可以连续执行两个命令

Q: hexo已经成功部署博客到github后，有时候发了新文章,发现github仓库已经更新了，但是访问博客网址却没更新？

1. `hexo clean`把本地的差分文件清理一下,再`hexo g & hexo d`
2. 等会儿时间,有时候会需要10分钟以内的更新时间
2. 浏览器缓存问题,用手机浏览器先看一下对不对
